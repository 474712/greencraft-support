二、原创性声明

本人/本团队郑重声明：

  1. 代码原创性：参赛作品《园林电动工具多语种智能客服系统（GreenCraft Pro）》的全部源码为本团队自主研发，采用零依赖单文件架构（不使用任何第三方前端框架或 UI 库），未抄袭、未复制他人代码。完整 Git 提交历史随代码片段一并提交，可通过 git log 逐版本核对演进过程。
  2. 数据原创性：意图词表（48 张表 / 1939 条）与知识库（241 条 × 8 语种）为本团队逐条撰写与校对，其中知识内容参考了厂商公开的产品手册与安全规范（如 ANSI Z87.1 护目镜标准、CE 认证要求），并在文中标注来源依据；测试用例为中 / 英 / 法 / 德 / 西 / 意 / 荷 / 葡母语客服的真实问法，未使用引擎内置关键词表的直译版本。
  3. 品牌与型号声明：GreenCraft Pro 为本项目自建的演示品牌，作品中出现的 GC-480E、LM2100SP、P-500、GC-2000PW 等型号及 AB2100、GC-520-CH-18 等料号均为演示虚构，不对应任何真实厂商产品。作品的知识条目为基于公开产品资料整理的示例性内容，用于演示系统的检索与答复机制，不构成任何产品的官方维修指引。
  4. 数据与表述真实性：作品所引用的全部性能指标均为本团队实测所得，并随代码提交可复现脚本（node tests/run-tests.js / node tests/run-tests.js --set holdout.json / node tests/metrics.js / node tests/quick-replies.js）；凡属行业基准推算的数字均已标注"测算"字样与前提假设，未将测算值表述为实测值，亦未对系统尚未实现的能力作肯定式宣称。
  5. 第三方素材：作品所用字体为 Cormorant Garamond、DM Sans、IBM Plex Mono 及其开源中文字体，均以本地内嵌方式使用；除 GitHub Pages 托管外，运行时不请求任何外部资源。
