## 三、作品简介（提交正文栏位用 · 详版）

### 3.1 痛点

园林电动工具是出海占比最高的机电品类之一，其售后有三个绕不开的硬约束：

| 约束 | 表现 | 后果 |
|---|---|---|
| 故障即咨询 | "启动不了 / 没劲 / 异响 / 漏油"是售后的主要话题，且多数用户可自行解决 | 说明书式自助排查无效，用户直接退货或差评 |
| 语言即门槛 | 同一品牌需覆盖英、法、德、西、意、荷、葡多套语言与多套安全规范 | 一语种一客服，成本线性叠加 |
| 时区即成本 | 与欧美市场差 6–12 小时 | 人工无法覆盖 24 小时，夜间咨询积压到次日 |

三者的交集是：<b>多语种 × 全时段 × 低成本</b>的人工客服组合，在中小品牌那里算不过账。

### 3.2 方案

GreenCraft Pro 是一套<b>完全运行在浏览器里的多语种售后智能客服</b>：

- **一个文件即全部**——界面、字体、意图词表、知识库、决策引擎全部封装在单个 HTML 中。零依赖、零构建、零后端、零外部请求。品牌方拿到文件就能挂到自己的官网或电商 IM 上。
- **8 语种三处同时本地化**——界面文案、意图词表、知识条目各自独立撰写，不是把一份中文机翻成 8 种语言。英、中、法、德、西、意、荷、葡各自维护自己的问法特征与专业表述。
- **6 类意图 × 10 个品类自动路由**——故障诊断、养护保养、配件订购、保修咨询、选型对比、安全规范六类意图，各自的强/弱特征词表共 48 张、1939 条词条；覆盖草坪机、修枝剪、链锯、绿篱机、吹叶机、高压清洗机、割灌机、微耕机、碎木机、割草机器人十个品类。
- **241 条知识条目三维索引**——按「意图 × 品类 × 语种」组织。检索分两级：先在「意图 × 品类 × 语种」单元内对全部候选条目打分排序，命中且置信度达标则直接答复、置信度不足则发起追问确认；单元内无候选时，再沿「同语种通用 → 默认 → 英文回落」三级降级链兜底。中文用二元组、拉丁语种用词边界做相似度匹配。
- **决策透明化**——每条答复下方附一张「判定依据」卡片：命中了哪些强特征、识别出哪个品类与型号、走的哪条检索路径、置信度多少。智能体的内部决策从黑箱变成可审计对象。
- **品类动态快捷提问**——输入框上方的快捷提问卡随所选品类整体替换，不再是几个固定的死按钮：8 语种 × 10 品类共 **240 条**手写问题，每条都带机型名。**每一条都可直达答案**——点下去会命中对应品类的对应意图并直接作答，不会反过来再追问一遍。
- **宁可问、不硬答**——证据不足时用当前语种主动反问缺失信息，绝不编造；用户要求真人时生成结构化工单转人工，并给出等待期的自助路径。

### 3.3 效果（实测，可复现）

| 指标 | 实测值 | 口径 |
|---|---|---|
| 意图识别准确率 | **100%** | 352 / 352 条标注用例（调优集 280 + 留出集 72） |
| 品类识别准确率 | **100%** | 121 / 121 条（仅统计标注了品类的用例） |
| 知识库命中率 | **100%** | 精确 / 模糊 / 同语种通用条目合计 |
| 一次解决率 | **98.6%** | 无需澄清、无需转人工即给出对应答复 |
| 转人工 · 澄清 · 寒暄流程探针 | **100% / 100% / 100%** | 32 / 24 / 16 条真实问法 |
| 引擎决策时延 | **0.05 ms**（P95 0.08–0.10 ms） | 意图 + 品类 + 检索 + 答复生成 |
| 端到端首字可见 | **838 ms** | 浏览器实测，含拟人化思考停顿与逐字流式 |
| 外部网络请求 | **0** | 无 fetch / XHR / 第三方脚本 / 字体 CDN |

复现方式：`node tests/run-tests.js` / `node tests/run-tests.js --set holdout.json` / `node tests/metrics.js` / `node tests/quick-replies.js`（无需安装任何依赖，直接读取线上 `index.html`）。

### 3.4 边界（主动声明，不回避）

本作品是**规则引擎**，不是大模型系统；知识库为 241 条精编小样本；跨语种输入需先切换界面语种；工单不落库、不派发；IoT 联动与 AR 远程指导<b>均未实现</b>，属路线图能力。上述能力边界在《方案设计文档》第四章以"已实现 / 规划中"对照表逐条标注。

**本系统尚无实测的客户满意度（CSAT）、真实转人工率、真实退货率与复购率**——这类指标需在真实企业试点中采集，当前不作任何数值宣称。

### 3.5 商业化方向

- **路径 A · SaaS 订阅**：面向中小品牌，按会话量分档订阅，引擎端无按次计费成本。
- **路径 B · 私有化部署**：面向数据出域受限的大客户，一次性实施 + 年度维护 + 增量语种。

> 定价为拟定价，用于说明商业模型可行性与单位经济结构，**尚未产生任何真实收入或签约**。
