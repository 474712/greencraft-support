## 五、评委可能当场要求执行的命令

> 提前在本地跑通一遍，并把输出截图存在桌面备用。

```bash
node tests/run-tests.js                  # 280 条调优集回归
node tests/run-tests.js --set holdout.json   # 72 条留出集回归
node tests/quick-replies.js              # 240 条品类动态快捷提问回归（2211 条断言）
node tests/annotations.js                # 演示顶部解说条回归（71 条断言）
node tests/metrics.js                    # 生成全部实测指标
```

预期输出（2026-11-03 状态）：

```
样本 352 条｜意图准确率 100%｜品类准确率 100%
KB 命中率 100%｜一次解决率 98.6%｜澄清率 1.4%｜转人工率 0%
引擎时延 均 0.05–0.10ms / P95 0.07–0.21ms（本机 20 次实测区间）
探针：转人工 100%｜澄清 100%｜寒暄 100%

断言 2211 条｜通过 2211 条｜失败 0 条
断言 71 条｜通过 71 条｜失败 0 条
```

> 五条命令**不需要 `npm install`**，不依赖任何第三方包。Node ≥ 16 即可。
>
> **关于时延那一行**：脚本打印的是**当次实测值**，会随机器负载浮动（负载越高数字越大）。本机 20 次实测的均值为 **0.05–0.10 ms**、P95 为 **0.07–0.21 ms**，文档中一律按区间引用、不引用单点值。评委当场跑出的数字若落在该区间内，属于正常波动。

## 七、一句话收束

> 提交的材料要能独立回答评委的三个问题：**你做了什么**（方案设计文档）、**它到底行不行**（应用效果说明）、**你怎么证明**（可复现脚本 + 演示视频）。
> 三者必须指向同一个事实，不能各说各话。
